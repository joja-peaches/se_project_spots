# 📸 Project 3: **Spots**

*A simple image sharing platform*

---

## 📝 Description

**Spots** is a lightweight image sharing platform built for both web and mobile. Users can:

- 📷 Share images  
- 👤 Create and update personal profiles  
- ❤️ Interact with other users' content via the **like** button

---

## 🛠️ Tech Stack

Built using the following technologies:

- 🌐 **HTML**
- 🎨 **CSS**
- 🧠 **JavaScript**
- 🖌️ **Figma** (for UI design)
- 📱 **Responsive Design**
